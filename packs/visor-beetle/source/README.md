# Remix the Visor Beetle

The PNGs in the pack folder are the editable raster source for this export.
Use the 400×520 images for desktop clips and the 32×32 images for cursors.
Keep the artwork on a transparent canvas. The cursor hotspot is at (10, 5),
measured from the top left. Change the frame order or timing in `pack.json`.

The original state and cursor timing references are linked in
[ATTRIBUTION.md](../ATTRIBUTION.md). The appearance falls back to the idle
animation when no state matches. Pick any other pack's voice alongside it.
